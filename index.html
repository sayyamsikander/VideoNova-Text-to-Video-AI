What the browser needs

1

Chrome / Edge

Use a current Chromium browser with hardware acceleration enabled. The engine requires WebGPU and the shader-f16 GPU feature.

2

Model download

The first visit downloads public Stable Diffusion ONNX model files. This is a large download and is the main reason initial loading can take time.

3

Generation

Text-to-Video Zero generates eight temporally linked frames on the visitor's GPU. No prompt is sent to a VideoNova server because there is no VideoNova backend.

4

Download

After generation, the page animates the eight frames. Download WebM records that animation in your browser.

If Generate never enables

Read the exact status shown on the Create page. If it says WebGPU unavailable or GPU F16 unsupported, that is a device/browser capability problem—not an internet error. If model download fails, reload once and check that large downloads from public model hosting are not blocked by your network.
