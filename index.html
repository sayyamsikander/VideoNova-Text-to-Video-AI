A

Hugging Face — easiest online setup

Install the Python dependency, create a Hugging Face token with Inference Providers permission, then put it in your environment. Your token stays on the server and is never sent to the browser.

pip install -r requirements.txt
export HF_TOKEN=hf_your_token_here
./start.sh

Default routed provider: fal-ai. You can change it with HF_PROVIDER.

B

ComfyUI — no API bill

Run ComfyUI locally, load a text-to-video workflow such as Wan 2.2, then export the workflow in API format. Save it as config/comfyui_api_workflow.json.

Replace the values you want this website to control with placeholders:

__PROMPT__
__NEGATIVE_PROMPT__
__SEED__
__WIDTH__
__HEIGHT__
__FRAMES__
__FPS__

The workflow must include a node that saves the final video so the server can fetch it from ComfyUI history.

C

Start the site

Copy .env.example to .env, add your preferred engine settings, and run the included launcher.

# macOS / Linux
cp .env.example .env
./start.sh

# Windows
python server.py

Open http://127.0.0.1:8080.

D

GitHub Pages backend

GitHub Pages can host this interface, but it cannot run server.py. After deploying the Python backend on a server host, paste its HTTPS URL here.

Leave empty when running the frontend and backend on the same server.
