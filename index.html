How VideoNova works

1

Open this website

There is no installer, login screen, API key, Python service, or separate backend. The published GitHub Pages site is the application.

2

Click Generate

On first use the browser automatically downloads the public AI model files. They are cached by the browser so later loads can be faster.

3

Your GPU does the work

WebGPU runs the diffusion model on the visitor's own compatible GPU. Chrome or Edge with hardware acceleration is recommended.

4

Download the MP4

The generated frames are encoded in the browser with WebCodecs and returned as an MP4 Blob that can be previewed and downloaded immediately.

Compatibility

Video generation is compute-heavy. A modern desktop/laptop GPU and recent Chromium browser are strongly recommended. Low-memory devices may fail or be slow. This limitation comes from running the AI locally in the browser rather than using a cloud GPU.
