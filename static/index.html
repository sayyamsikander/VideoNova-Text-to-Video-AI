Run VideoNova yourself

1

Install the local AI runtime

Clone or download this repository on the computer that has your GPU, then install the included Python packages.

python -m pip install -r requirements.txt

An NVIDIA GPU with roughly 11GB+ VRAM is the practical target for the default Wan 2.1 1.3B model. Apple Silicon can also be attempted through MPS.

2

Download the open model

No account or token is needed. Download the public model once; it is saved in models/ and future generations use the local files.

python download_model.py

Automatic first-run download is enabled by default. You can disable it in .env after the model is present.

3

Start your own generator

Run the included launcher. The website and AI backend are served from the same computer.

# Windows
start.bat

# Linux / macOS
bash start.sh

Open http://127.0.0.1:8080. No external account is connected.

4

About GitHub Pages

The GitHub Pages address can display the interface, but GitHub Pages does not provide a GPU or execute Python. For generation, open the local URL above or host this same repo on a GPU machine you own.

The AI itself runs in server.py using the local open-source model files.
